# Grounding Rules & Standards

This document establishes baseline rules and conventions that the agent must adhere to when this plugin is enabled.

## Core Principles
1. **Consistency**: Follow existing architectural patterns, naming conventions, and style rules across the repository.
2. **Quality & Verification**: Validate changes with relevant tests and linting before completing tasks.
3. **Documentation**: Keep documentation in sync with codebase changes.

## Coding Conventions
- Maintain high test coverage for core business logic.
- Prefer explicit contracts and types over loosely typed alternatives.
- Ensure all public APIs and components have clear documentation comments.
